# Face Detection System

A real-time Face Detection System built using Python and OpenCV.

## 📌 Project Overview

This project uses a webcam to detect human faces in real time using Haar Cascade Classifiers from OpenCV.

The system captures video frames, processes them, and draws rectangles around detected faces.

---

## 🚀 Features

- Real-time face detection
- Webcam integration
- Face tracking using OpenCV
- Simple and beginner-friendly
- Fast processing

---

## 🛠 Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
